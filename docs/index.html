Small Matter · Official support

How can we help?

Setup instructions, troubleshooting, and a direct path to request help with Small Matter, the local system-monitoring and diagnostics utility.

Contact support

Have a question, found a bug, or need help using a feature? Open a support request in the Small Matter issue tracker. Include your macOS version, Small Matter version, what you expected, what happened, and steps to reproduce when possible.

Ask a question or report a problem ↗

Submitting a GitHub issue requires a free GitHub account. You can read public issues without signing in. Do not post passwords, access tokens, serial numbers, private files, or unredacted diagnostic exports in a public issue.

Getting started

  1. Install Small Matter using the Mac App Store or the signed direct-download release.
  2. Open Small Matter from Applications.
  3. Start at Overview, then select Performance, Battery, Cooling, System Health, or Recent Changes to inspect local information.
  4. When needed, use Incident Capture or export a support/evidence summary to a location you choose.

No Small Matter account or sign-in is required.

Common questions

Why is a sensor marked “Unavailable”?

Some hardware readings depend on the Mac model, operating system, and App Sandbox restrictions. Small Matter reports unavailable measurements rather than estimating them.

Does Small Matter control fans or charging?

No. Hardware telemetry is read-only. macOS retains control over fans, charging, and thermal policy.

Where is my diagnostic data sent?

Observations are processed locally. Files are shared only when you explicitly choose to export or send them.

Troubleshooting checklist

  • Confirm you are using a supported macOS version and the latest installed Small Matter release.
  • Quit and reopen Small Matter, then revisit the affected screen.
  • Note whether the issue occurs consistently, and whether it involves a particular peripheral or hardware sensor.
  • If relevant, use the in-app support/evidence export after reviewing its contents for private information.

For reproducible defects, open a support request. For existing reports, browse known issues.

Privacy and safety

Small Matter has no advertising, analytics, tracking, cloud telemetry, or account system. Cleanup, where available, is user-scoped and designed around quarantine and undo. Incident and evidence exports remain user-initiated. Before sharing an export, review it and remove any details you do not want to disclose publicly.

For technical and privacy documentation, see the Small Matter project repository.
